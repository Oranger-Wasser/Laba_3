# Лабораторная работа № 3 — анализ адресов

Консольная программа читает CSV и XML, находит дубли, считает здания по этажности в каждом городе и измеряет время обработки.

## Запуск

```bash
python main.py
```

Укажи путь к `address.csv` или `address.xml` из задания. Входные файлы хранятся отдельно от репозитория. После отчёта можно ввести следующий путь или `exit`. Программа использует стандартную библиотеку Python.

## Входные данные

Поля записи — `city` (город), `street` (улица), `house` (номер дома), `floor` (этажность). Этажность должна быть положительным целым числом. Порядок полей произвольный.

В CSV поля записаны через точку с запятой.

```csv
city;street;house;floor
Барнаул;Дальняя улица;56;2
```

В XML поля заданы атрибутами записи внутри корневого элемента.

```xml
<addresses>
    <building city="Барнаул" street="Дальняя улица" house="56" floor="2" />
</addresses>
```

## Подсчёт статистики

Дублем считаются записи с одинаковыми городом, улицей, номером дома и этажностью. Программа показывает число появлений каждой повторяющейся записи. В сводке по этажам от 1 до 5 каждая уникальная запись учитывается один раз.
